# Provenance and scope

These are newly authored portable skills and a new generic starter, informed by the owner's local `Movies/gtm-os` reference library. They are not exports of the library's original projects or of an internal skill collection.

The inspected examples were:

| Local project | Reusable lesson |
| --- | --- |
| `channels-sdk` | Shared channel registry, consistent logo containers, causal chat/approval sequences, code scenes, per-scene posters |
| `aimock` | Problem-led developer narrative, code as the subject, evidence for numeric claims, a useful opening thumbnail |
| `agui-subagents-diagram` | Complete static diagram on frame zero, exact loop periods, attribution tied to topology |
| `openmuse-demo/launch-source` | Frame-driven Remotion scenes, original audio workflow, asset provenance and explicit illustrative-demo disclosure |
| `opendots/05_Code` and editor notes | Native-resolution inventory, editable source handoff, safe margins, consistent dark treatment, actual UI recordings |

The source archive also contains older and superseded revisions. Its defects are not defaults for these skills. In particular, editorial cropping of recorded UI does not satisfy a request to enlarge the application before capture.

Only general production techniques are carried over. Private source code, third-party logos, original mascots, original video/audio files, internal URLs, message text, account details, and local absolute paths are not included.

The fictional starter is new code. Its typeface is installed through `@fontsource/inter`; its runtime dependencies and licenses are recorded in the starter package and lockfile. No product metrics or vendor integration claims from historical videos are repeated as current facts.
